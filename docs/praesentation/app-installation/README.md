# TFB-App-Installation – Vorstandspräsentation

Die PNG-Dateien zeigen den echten Dialog der App in einer 390px breiten Mobilansicht
mit fünffacher Pixeldichte (1950px Bildbreite). Beide Reiter sind unverändert aus der
Produktionsoberfläche gerendert, keine grafisch nachgebauten Mockups.

- TFB-App-Apple-iPhone-iPad-HD.png: Safari-Anleitung für iPhone/iPad.
- TFB-App-Android-HD.png: Chrome-Anleitung für Android.

Erreichbar nach mobiler Anmeldung über „So geht’s“, jederzeit über den Account sowie
für Admins direkt über „App-Anleitung“. Auch im bereits installierten App-Modus bleibt
der manuelle Aufruf erreichbar. Je nach Gerät/Breite und verfügbarem nativem Android-
Installationsdialog können Fensterhöhe und zusätzliche Installationsschaltfläche abweichen.

Neu erzeugen: node tools/export-install-guide.mjs
